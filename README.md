# Gestor de Biblioteca Personal

Aplicación web desarrollada como módulo práctico para la asignatura **Herramientas Avanzadas para el Desarrollo de Aplicaciones (102HAD1)** de la UTLA, utilizando un asistente de Inteligencia Artificial como apoyo de programación.

## Funcionalidades
1. **Registrar libros:** Permite ingresar título, autor y género académico.
2. **Listar libros:** Muestra los registros almacenados en una tabla interactiva.
3. **Eliminar libros:** Remueve elementos específicos del catálogo con persistencia en LocalStorage.

## Instrucciones para ejecutar
1. Clona o descarga este repositorio.
2. Abre el archivo index.html en cualquier navegador web moderno." > README.md
